KargoPilot 1.1.1

- Firma logoları sabit boyutlu kutulara sığıyor. Yüklenmeyen görsellerin yerinde firma kısaltması gösteriliyor.
- Yurtiçi Kargo, Trendyol Express, CEVA ve YunExpress logoları eklendi.
- Koyu tema füme yüzeyler ve hafif mavi vurgular kullanıyor.
- Gönderi detayından API hesabı olmadan resmî takip sayfasını açabilir veya numarayı doğrudan 17TRACK’e aktarabilirsin. Kolay Gelsin bağlantısı gönderi sorgulama formunu açıyor.
- Uygulama içindeki otomatik hareket geçmişi ve bildirimler için kişisel 17TRACK API hesabı gerekiyor.

KargoPilot.apk önceki sürümle aynı imza anahtarını kullanır.
